# execucao-NB

Saídas produzidas pela **execução do notebook** `notebooks/02_pipeline_plano_simples.ipynb`.

Separado de `output/` de propósito:

| pasta | quem escreve | o que é |
|---|---|---|
| `output/` | `python src/main.py` | a entrega oficial do case |
| `execucao-NB/` | o notebook | material de conferência da narrativa executada |

Nada aqui é entregável: é descartável e pode ser regenerado reexecutando o notebook.
Os arquivos não são versionados (veja `.gitignore`); só este README é.
